# InMoment 1.0.0

Windows 11 x64 · 首个稳定版 · 2026-11-26

InMoment 把语音、截图和来源整理成可以编辑的笔记。笔记可分组、搜索和导出，也可以连同附件一起引用到 AI 聊天。

## 本版更新

- 安装向导可选择程序目录和桌面快捷方式。安装包包含离线语音转写、本地语义检索和图片 OCR。
- 聊天可以引用多篇笔记及其附件。整段聊天或所选消息可保存到选定分组，或存为所引用笔记的附件。复制聊天内容到笔记时保留常用格式和公式。
- 录音和聊天内容可追加到已有笔记。笔记中的公式可以继续编辑，图片右键提供复制和提取文字等操作。
- 一键 AI 总结生成可编辑的笔记，并可选用相关的原笔记图片配图。
- 长按录音快捷键可打开录音卡片。「启动自动录音」可在「设置 → 操作」中调整。
- 支持自定义快捷键。离开设置时会处理尚未保存的改动。
- 「使用帮助」可提交反馈，回复邮箱选填。反馈服务升级后支持图文反馈。

## 安装与升级

1. 打开下载页并点击「下载 Windows 版」。[InMoment 下载页](https://ienqi.github.io/InMoment/)
2. 已有旧版时，先从系统托盘退出 InMoment，并备份 `%APPDATA%\InMoment`。
3. 打开 `InMoment-Setup-1.0.0-x64.exe`，按向导选择安装目录。升级沿用当前 Windows 账户下的笔记和设置。

下载页也提供 SHA-256 校验文件。电脑缺少 VC++ x64 运行库时，安装向导会征得同意，再从微软下载安装。安装包目前未进行 Windows 代码签名。

本地笔记、转写和图片识别无需 API Key。云端 AI 默认关闭，启用时在设置中选择服务商并填写自己的密钥。
